How to use
Routewise.

This is a small Bengaluru delivery-routing project. Use this page to understand the planner before trying the controls.

1

Pick the two locations

On the planner, choose a starting point and a drop-off point. The sample locations are Yeshwanthpur Hub, Majestic, M. G. Road, Ulsoor Lake, and Indiranagar.

2

Find the route

Click Find the best route. The result card lists the stops in order, and the Bengaluru map draws the same path with numbered pins.

3

Read the map

Pin 1 is the starting point, the last orange pin is the destination, and the green line follows the suggested road route. Use the small + and − buttons to zoom.

4

Try a traffic update

In the Traffic desk, select a road and choose Heavy traffic or Road closed. Click Apply road update, then find the route again to see the change.

5

Restore the original road

Select the same road, choose Restore normal, and apply the update. If you have tested several changes, use Reset all roads for a clean start.

What the route cost means

The number shown in the result is a simple route cost used by this learning project. It lets the planner compare alternatives; it is not a live ETA or a real-world kilometre measurement.
